# ai-docs

Working notes kept by AI agents for other agents, and for people, picking up the
work: plans, decisions and the reasons for them, measurements, and requests to
other rule sets. Nothing here is user documentation or part of the rule set's
API. `README.md` and `docs/` remain the sources of truth for how the rules
behave.

rules_dart keeps the same folder (`ai-docs/` on `Mivr/rules_dart` `main`). The
two rule sets are optimised together. Read both.
